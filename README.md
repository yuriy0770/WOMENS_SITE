## 📖 О проекте

WomenSite - это веб-платформа, посвященная удивительным женщинам, которые вдохновляют своими достижениями, талантами и историями успеха. Проект создан для того, чтобы:

- 🎯 **Знакомить** с выдающимися женщинами из разных сфер деятельности
- 💫 **Вдохновлять** историями успеха и достижений  
- 👥 **Объединять** сообщество единомышленников
- 📚 **Сохранять** знания о значимых личностях

## ✨ Особенности

### 🎨 Пользовательский интерфейс
- **Современный дизайн** с темной темой Bootstrap 5
- **Адаптивный layout** для всех устройств
- **Интуитивная навигация** с боковым меню категорий
- **Красивые карточки** с hover-эффектами

### 🔧 Функциональность
- 📋 **Каталог женщин** с фильтрацией по категориям
- 👤 **Система пользователей** с профилями
- 🔐 **Авторизация** и регистрация
- ➕ **Добавление контента** авторизованными пользователями
- 🔍 **Умный поиск** по имени, описанию и категориям
- 🖼️ **Загрузка изображений** для профилей и категорий

### 🛠 Технологии
- **Backend**: Django 4.2, Python 3.8+
- **Frontend**: Bootstrap 5, JavaScript
- **Database**: PostgreSQL
- **Icons**: Bootstrap Icons
- **Templates**: Django Template Language
